# 지금 뭐 먹지 (일본 여행용 맛집 찾기)

휴대폰 브라우저에서 여는 웹앱입니다. 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 기능
- 현재 위치(GPS) 또는 역·지명 입력으로 기준 위치 설정
- 음식 선택: 스시, 야키니쿠, 라멘, 돈카츠, 디저트 등 + 직접 입력 (일본어 검색어로 자동 변환)
- 조건: 반경(200m–5km), 최소 별점, 최소 리뷰 수, 가격대, 지금 영업 중
- 전망: 바다·오션뷰 / 야경·높은 전망 / 정원·자연 / 강변 / 후지산·산
  - 가게 이름과 구글 리뷰에서 전망 관련 표현(일·한·영)을 찾아 점수를 매김
- 추천순(별점 신뢰도 + 거리 + 전망 점수), 가까운순, 별점순 정렬
- '아무거나 골라줘': 상위 5곳 중 하나를 무작위로 선택
- 자주 쓰는 조건 저장, 원탭 길찾기(구글맵 도보)

## 처음 설정 (10분)
1. https://console.cloud.google.com 에서 프로젝트 생성 후 결제 계정 연결
2. "Maps JavaScript API", "Places API (New)" 사용 설정
3. 사용자 인증 정보 → API 키 생성 → 애플리케이션 제한: 웹사이트, 앱 주소 등록 (예: `https://아이디.github.io/*`)
4. 예산 알림 설정 권장 (결제 → 예산 및 알림)
5. 앱 오른쪽 위 'API 키 설정'에 키 입력

## 휴대폰에서 쓰기
GPS는 https 주소에서만 동작하므로 GitHub Pages 같은 곳에 올려야 합니다.
이 폴더의 파일(index.html, manifest.json, icon.svg, icon-180.png, icon-512.png)을
GitHub 저장소에 올리고 Settings → Pages에서 활성화하면 됩니다.
iPhone은 Safari 공유 → '홈 화면에 추가', Android는 Chrome 메뉴 → '홈 화면에 추가'.
