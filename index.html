Google API 키

실제 가게 정보(별점, 리뷰, 영업시간)는 Google 지도에서 가져와요. 키는 이 휴대폰 브라우저에만 저장돼요.

  2. Maps JavaScript API와 Places API (New) 사용 설정
  3. 사용자 인증 정보 → API 키 만들기 → 웹사이트 제한에 이 앱 주소 등록
